# Jinder frontend

React 19 + Vite dashboard for Jinder. See the [root README](../README.md) for
full setup instructions.

```bash
npm install        # in this directory
npm run dev        # dev server on :5173, proxies /api to the backend on :5000
npm run build      # production build into ../dist/frontend (served by the backend)
npm run lint       # eslint
```
